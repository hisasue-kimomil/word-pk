# ①課題名
ワードPK（自分の言葉を保存して、PKに勝ったら出てくるメモ帳アプリ）

## ②課題内容（どんな作品か）
- 自分の言葉（10個まで）を書いて保存できるメモ帳。思想家の言葉も10個用意した
- 出したい言葉にチェックを付けて［試合へ］を押すと、PK（5本中3本決めたら勝ち）が始まる
- 勝つと「★ 決勝トーナメント進出！ ★」と、チェックした言葉の中から1つが出る。負けると言葉は出ない
- 書いた言葉とチェックはブラウザ（ローカルストレージ）に保存され、開き直しても残る

## ⑤工夫した点・こだわった点
- 課題の4つを、飾りではなく中心の動きで使った
  - 配列：思想家の言葉、方向ごとの数、チェックして集めた言葉
  - 繰り返し（for）：一覧を作る、保存する、読み込む、5本のマークを戻す
  - 配列＋繰り返し：配列の言葉を for で1つずつ取り出して一覧を作る
  - ローカルストレージ：言葉とチェックを保存し、開き直しても残す
- 入力欄と保存の名前に同じ番号（myword0〜9 など）を付け、for で番号を変えるだけで10個まとめて保存・読み込みできるようにした
- 勝ったときだけ自分の言葉が出るので、遊ぶほど言葉が自分のものになる
- 方向のボタンをゴールの形（左上・右上／真ん中／左下・右下）に並べ、どこに蹴るかが見て分かるようにした
- 試合が終わっても言葉の画面に戻らず、続けて遊べる。言葉を変えたいときだけ［言葉を入れ替える］で戻る

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 前回の「5方向に同じ処理を写したので量が多い」を、方向ごとの数を配列にまとめ、蹴る処理を隠しボタン（kick）の1か所にして解いた。script.js は 693行から約280行になった
- コードを置く場所（{ } の中か外か）で、動くときが変わる（ページを開いたとき／ボタンを押したとき／条件に当てはまったとき）ところに苦労した
- 次は「関数」を使って、処理をさらに整理したい。保存も、配列をまとめて1つに保存する書き方（JSON）を試したい
